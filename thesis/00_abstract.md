# Abstract

Freelancers with irregular income need to know when a transaction is unusual and why. This thesis builds a pipeline that flags unusual spending with an LSTM autoencoder, explains each flag in plain language, and produces an educational tax set-aside note, and it concentrates on evaluating each stage honestly. I worked with a public, synthetic-looking personal-finance dataset (15,900 rows, 150 users, amounts in rupees). Auditing it showed that the original data loader silently discarded 69% of the rows, and that the class-project evaluation, which injected values outside the range any real input can take, did not measure realistic detection. Re-evaluating by changing one raw amount and then processing the result like real data showed that the original detector was at chance. Scaling each amount relative to the user's typical amount raised recall at a 5% false-positive rate to 49.7 ± 3.5% for a charge ten times too large (five-fold cross-validation over users). However, a one-line untrained rule reached 74.4 ± 1.7% when it knew the anomaly would be a spike, and the data showed no per-user or time structure for a sequence model to exploit. For explanations, a deterministic fact layer, a small local language model (llama3.2:3b), and an automatic grounding check with a template fallback produced text that met all four quality criteria for 90% and 95% of 20 sampled flags in the last two evaluation rounds, compared with 90% and 100% for a rule-based template; with 20 samples these are statistically indistinguishable. The contributions are a data and evaluation audit, a verification-first explanation design, and negative results that bound what this dataset can show about learned detectors.
