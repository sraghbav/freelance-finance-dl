# Abstract

Freelancers with irregular income need to know when a transaction, an expense or a payment received, is unusual and why. This thesis builds a pipeline that flags unusual amounts with an LSTM autoencoder, explains each flag in plain language, and produces an educational tax set-aside note, and it concentrates on evaluating each stage honestly. I worked with a public, synthetic-looking personal-finance dataset (15,900 rows, 150 users, amounts in rupees) and a second, simulated card-transaction dataset with real fraud labels. Auditing the first dataset showed that the original loader silently discarded 69% of the rows, that windows mixed income with expenses and contained almost no income, and that the class-project evaluation, which injected values outside the range any real input can take, did not measure realistic detection. Re-evaluating by changing one raw amount and processing the result like real data showed that the original detector was at chance. Scaling each amount relative to the user's typical amount raised recall at a 5% false-positive rate to 41.0 ± 3.7% for a charge ten times too large (five-fold cross-validation over users), but a one-line untrained rule reached 73.6 ± 4.1% when it knew the anomaly would be a spike, and for unexpectedly low income it caught 94.7 ± 1.4% of tenfold drops against 8.3 ± 0.9% for the autoencoder. On real fraud labels the best autoencoder at most tied the rule (average precision 0.070 for both; AUROC 0.708 against 0.732), and neither dataset has the time structure a sequence model needs. For explanations, a deterministic fact layer, a small local language model (llama3.2:3b), and an automatic grounding check with a template fallback produced text that was fully correct for 95% of 20 sampled flags in the final round, compared with 100% for a rule-based template; these are statistically indistinguishable, and the model was brittle to small prompt changes. The contributions are a data and evaluation audit, a verification-first explanation design, and negative results that bound what these datasets can show about learned detectors.
